# Objetivo
Esse repo reproduz a plataforma que foi criada aqui do zero [Quant-Guild] https://github.com/romanmichaelpaolucci/Quant-Guild-Library/tree/main/2026%20Video%20Lectures/130.%20Projects%20to%20Help%20you%20Become%20a%20Quant%20(Beginner)/02%20-%20Quant%20Researcher/01%20-%20Intro%20-%20Binomial%20Tree%20Pricer.

O objetivo principal é gerar uma calculadora de opções binomiais que me dê a possibilidade de estudar como parâmetros se relacionam. O back será feito usando python e o front feito com node js. 

O intuito principal do projeto é ter uma plataforma que um usuário possa inserir dados como Strike, Risk-free-rate, vol, e obter o valor do premio da opção.
